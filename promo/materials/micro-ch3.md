# 一、核心概念与定义

## 1.1 弹性的基本思想

弹性（elasticity）衡量一个经济变量对另一个经济变量变动的敏感程度。核心思想是：当价格上升 1%，需求量大约下降百分之几。这个百分比之比是无量纲的，因此可以在不同商品、不同市场、不同国家之间直接比较敏感度——这是弹性指标相比「价格变动 1 元引起需求变动多少件」这类有量纲指标的根本优势。

需要强调一点：弹性是一个「局部」概念还是「区间」概念，决定了对应的计算方式。在一条平滑的需求曲线上，每一点的弹性一般不同；即使需求曲线是直线，弹性的取值也随所处位置变化。因此在使用弹性时必须说清楚「在哪一点」或「在哪个区间」。

弹性的数值大小还与时间尺度相关：同一商品短期弹性通常小于长期弹性，因为短期内消费者调整消费结构的摩擦（换车、迁居、改变习惯）阻碍了充分反应，而长期内这些摩擦被时间消化。这个「时间维度」是判断某商品弹性高低时不能忽视的第三个维度（前两个是商品性质与替代可得性）。

## 1.2 四类弹性的定义

**需求价格弹性** $E_d$：需求量变动百分比与价格变动百分比之比。

$$E_d = \frac{\Delta Q / Q}{\Delta P / P}$$

按惯例讨论价格上升时需求量的反应，取绝对值形式。$E_d > 1$ 称为富有弹性，$E_d < 1$ 称为缺乏弹性，$E_d = 1$ 称为单位弹性。富有弹性的典型商品是可替代性强的非必需品（如某种品牌的饮料），缺乏弹性的典型商品是短期内难以找到替代品的必需品（如急救药品、短期内难以搬离的住房）。

**收入弹性** $E_I$：需求量对收入变动的敏感程度。

$$E_I = \frac{\Delta Q / Q}{\Delta I / I}$$

$E_I > 0$ 为正常商品，$E_I > 1$ 为奢侈品（需求增长快于收入增长），$0 \le E_I \le 1$ 为必需品（需求增长慢于或不快于收入增长），$E_I < 0$ 为劣等品（income effect 为负，收入上升反而减少需求）。经验研究表明，随着收入水平提高，食品的收入弹性会下降——这正是著名的恩格尔定律的弹性表述。恩格尔定律还可以表述为：食物支出占总支出的份额随收入上升而下降，这是食物收入弹性小于 1 的直接推论。

**交叉弹性** $E_{xy}$：商品 $x$ 的需求量对商品 $y$ 价格变动的敏感程度。

$$E_{xy} = \frac{\Delta Q_x / Q_x}{\Delta P_y / P_y}$$

$E_{xy} > 0$ 表示两者是替代品（对方涨价我多买），$E_{xy} < 0$ 表示互补品（对方涨价我少买），$E_{xy} \approx 0$ 表示两者需求相互独立。计算交叉弹性时必须分清「哪个是价格方、哪个是数量方」，$E_{xy}$ 与 $E_{yx}$ 在数值上一般并不相等。

**供给价格弹性** $E_s$：供给量对价格变动的敏感程度，形式与需求弹性对称。

$$E_s = \frac{\Delta Q_s / Q_s}{\Delta P / P}$$

供给弹性在短期内往往低于长期内：短期内产量受设备与产能约束，价格上升难以迅速扩产；长期内厂商可以进入或退出市场、调整资本规模，供给弹性明显更大。农产品市场是典型的例子——收获季节的供给几乎缺乏弹性（产量已经固定），价格可以剧烈波动；跨期看，农民可以调整播种面积，长期供给弹性显著大于短期。

## 1.3 点弹性与弧弹性

**点弹性**衡量的是需求曲线上某一点处的瞬时敏感程度，定义为导数之比：

$$E_{d,\text{点}} = \left|\frac{dQ}{dP} \cdot \frac{P}{Q}\right|$$

对线性需求 $Q = a - bP$ 代入可得 $E_d = |{-bP / (a - bP)}|$，可见即使斜率 $-b$ 恒定，弹性也随价格位置变化：价格高时弹性大，价格低时弹性小。

**弧弹性**用于两点之间。如果用起点做基数，价格从 $P_1$ 涨到 $P_2$ 与从 $P_2$ 跌回 $P_1$ 算出的弹性不同，产生「基期歧义」。弧弹性（arc elasticity）取两端的中点作为基数，彻底消除该问题：

$$E_{d,\text{弧}} = \frac{\Delta Q / \bar{Q}}{\Delta P / \bar{P}}, \qquad \bar{Q} = \frac{Q_1 + Q_2}{2},\ \bar{P} = \frac{P_1 + P_2}{2}$$

弧弹性对「涨价」与「跌价」两个方向给出相同数值，是实证研究中最常用的形式。当区间足够小时，弧弹性收敛于点弹性。

## 1.4 消费者剩余与生产者剩余

**消费者剩余**（consumer surplus, CS）是消费者愿意支付的最高价格与实际支付价格之间的差额之和。在图形上表现为需求曲线下方、价格线以上的面积：

$$CS = \int_0^{Q^*} P^*(Q')\, dQ' - P^* Q^*$$

其中 $P^*(Q')$ 是需求反函数。直觉上：每个消费者为第 $i$ 单位商品愿意支付的最高价格是 $P^*(i)$，实际支付 $P^*$，差额之和即消费者剩余。在线性需求 $P = a - bQ$ 下可直接算出：$CS = \tfrac{1}{2}(a - P^*)Q^*$，即底为 $Q^*$、高为 $a - P^*$ 的三角形面积。

**生产者剩余**（producer surplus, PS）是实际价格与厂商愿意接受的最低价格（边际成本）之间的差额之和，即供给曲线以上、价格线以下的面积：

$$PS = P^* Q^* - \int_0^{Q^*} MC(Q')\, dQ'$$

在线性供给 $P = c + dQ$ 下：$PS = \tfrac{1}{2}(P^* - c)Q^*$。

两者之和称为**总剩余**（social surplus）。在完全竞争均衡点，总剩余达到最大：均衡数量恰好使「最后 1 单位的边际价值」等于「最后 1 单位的边际成本」。任何偏离均衡数量的交易（无论是过量还是不足）都会产生无谓损失（deadweight loss）：过量交易时边际成本超过边际价值，不足交易时边际价值超过边际成本。

**价格管制下的剩余变化**。最高限价（price ceiling）若低于均衡价格，造成短缺，总剩余减少，出现黑市价格与排队损耗；最低限价（price floor）若高于均衡价格，造成过剩。两种管制下的无谓损失在图形上都是「消失的三角形」——对应于未发生交易的边际价值与边际成本之差的积分。

## 1.5 替代效应、收入效应与替代弹性

把名义收入固定在 $m$，把商品 1 的价格从 $p_1$ 降到 $p_1'$。总需求变化 $\Delta Q_1$ 可分解为两步：

1. **补偿预算**：把预算提高到 $m + (p_1 - p_1') q_1^0$，使消费者在原消费束处的购买力不变。此步只改变相对价格，产生的需求变化是**替代效应**，恒为负（价格上升使该商品相对更贵，消费者转向替代品）；
2. **实际收入变化**：预算从补偿水平回到原水平 $m$，产生**收入效应**。对正常品收入效应与替代效应同向（价格下降→实际收入上升→多买）；对劣等品两者反向。

**吉芬商品**是劣等品中的极端情形：收入效应为负且绝对值大于替代效应，价格上升反而增加需求量。吉芬商品必须同时满足「劣等品」与「收入效应压倒替代效应」两个条件，现实中几乎不存在（爱尔兰马铃薯饥荒中的马铃薯是历史上的经典案例）。

**替代弹性**（elasticity of substitution）衡量保持实际收入不变时，两种商品之间替代的容易程度。它在生产理论中同样核心：两种投入（劳动与资本）的替代弹性决定长期生产中要素使用比例随相对价格调整的快慢。替代弹性越大，等产量曲线越平缓，要素间越容易互相替代。

## 1.6 弹性的经验规律与分类

需求价格弹性在经验上可以按商品的性质与时间维度归纳出几条规律，这些规律是预测市场行为的实用工具：

- **必需品 vs 奢侈品**：必需品（食品、食盐、基础医疗）缺乏弹性，因为缺乏替代选择；奢侈品富有弹性，消费者可以在价格过高时推迟购买或转向替代品；
- **用途广 vs 用途窄**：电、汽油等用途广泛的商品缺乏弹性（所有用途加总后替代选择有限），而「汽油用于长途自驾」这一狭窄用途富有弹性；
- **时间维度**：长期弹性总是大于短期弹性。短期受习惯、合同、信息约束，长期内消费者有充分时间调整消费结构（如换车、迁居）；
- **市场范围**：窄市场（「左轮手枪」）比宽市场（「枪支」）弹性更大，因为替代品更少。

供给弹性同样有时间维度：农产品收获期内供给几乎完全无弹性（产量已定），跨期则可通过调整播种面积增大供给弹性。

## 1.7 弹性在经营中的应用

弹性直接服务于三个常见的商业决策场景：

**第一，定价与总收益**。对富有弹性（$|E_d| > 1$）的商品，降价提高总收益；对缺乏弹性（$|E_d| < 1$）的商品，涨价提高总收益。航空公司动态定价对「价格敏感、可推迟出行」的客群使用低价（弹性大），对「时间紧迫、刚需出行」的客群使用高价（弹性小），本质上是在不同需求段上分别利用弹性差异。

**第二，税收归宿**。对需求缺乏弹性的商品征税，税负主要落在消费者头上（价格上升，购买量变化小）；对供给缺乏弹性的商品征税，税负主要落在生产者头上。烟草、盐等高税商品的税收设计正是利用了需求缺乏弹性的特点。

**第三，市场划分与竞争战略**。两个市场间需求弹性不同且不能转卖（arbitrage 不可能）时，厂商可以对弹性小的市场定高价、对弹性大的市场定低价，实现二级价格歧视，提高总利润。

# 二、弹性的几何与微积分视角

## 2.1 需求曲线上的弹性分段

对一条线性需求曲线 $Q = a - bP$（截距 $a > 0$），弹性沿曲线连续变化，可以画出完整的弹性图谱：

- 数量轴截距（$P = 0$ 处）：$E_d \to 0$，需求完全缺乏弹性；
- 价格轴截距（$Q = 0$ 处）：$E_d \to \infty$，需求完全富有弹性；
- 曲线中点：$E_d = 1$，单位弹性。

**微积分结论**：$E_d = \frac{a - bP}{bP} \cdot \frac{bP}{a - bP}$ 的分子分母之比恒为 1 当且仅当 $P = a/(2b)$——中点。这条「中点单位弹性」规律在线性需求曲线上恒成立，是定价与税收分析中最常用的快速定位工具。

## 2.2 总收益与弹性的一阶条件

总收益 $R(P) = P \cdot Q(P)$。对价格求导并应用链式法则：

$$\frac{dR}{dP} = Q + P\frac{dQ}{dP} = Q\left(1 + \frac{dQ}{dP}\frac{P}{Q}\right) = Q(1 - E_d)$$

其中 $E_d > 0$ 为取绝对值后的弹性。一阶条件 $\frac{dR}{dP} = 0$ 给出 $E_d = 1$——总收益在单位弹性处达到最大值。

**二次导数与经济含义**：

$$\frac{d^2R}{dP^2} = \frac{dQ}{dP}(1 - E_d) + Q \cdot \frac{d(1-E_d)}{dP}$$

在线性需求曲线上，$E_d$ 随价格上升而上升，故 $E_d < 1$ 段（低价段）$dR/dP > 0$，涨价增收；$E_d > 1$ 段（高价段）$dR/dP < 0$，降价增收。

**经验规则**（用于经营判断，不需微积分推导）：

| 弹性区间 | 涨价对总收益 | 降价对总收益 | 典型场景 |
|---|---|---|---|
| $E_d > 1$（富有弹性） | 减少 | 增加 | 可选品、奢侈品、有替代品的商品 |
| $E_d = 1$（单位弹性） | 不变 | 不变 | 线性需求曲线中点 |
| $E_d < 1$（缺乏弹性） | 增加 | 减少 | 必需品、成瘾品、短期供给受限时 |

# 三、核心公式速查

| 公式名称 | 表达式 | 适用场景 |
|---|---|---|
| 需求价格弹性（点） | $\frac{dQ}{dP}\cdot\frac{P}{Q}$ | 需求曲线某点处 |
| 需求价格弹性（弧） | $\frac{\Delta Q/\bar{Q}}{\Delta P/\bar{P}}$ | 价格区间整体反应 |
| 收入弹性 | $\frac{\Delta Q/Q}{\Delta I/I}$ | 判断商品档次 |
| 交叉弹性 | $\frac{\Delta Q_x/Q_x}{\Delta P_y/P_y}$ | 判断替代与互补关系 |
| 供给弹性 | $\frac{\Delta Q_s/Q_s}{\Delta P/P}$ | 判断供给对价格反应 |
| 消费者剩余 | $\int_0^{Q}P^*(Q')\,dQ'-PQ$ | 福利分析 |
| 总收益对价格求导 | $\frac{dR}{dP}=\frac{Q(1-E_d)}{E_d+1}$ | 定价策略 |

**公式记忆要点**：弧弹性的中点 $\bar{P}, \bar{Q}$ 是「两端相加除以二」；总收益求导公式的分子 $(1-E_d)$ 揭示了弹性与收益方向的分界——$E_d=1$ 时总收益对价格不敏感（处于极值点）。

# 四、例题详解

## 例题 1：弧弹性的计算与总收益判断

某咖啡品牌在价格为 30 元时，月销售量为 1200 杯；价格降至 24 元后，月销售量增至 1800 杯。求该价格区间的弧弹性，并判断降价是否提高总收益。

**解答**

先算中点：$\bar{P} = \frac{30 + 24}{2} = 27$，$\bar{Q} = \frac{1200 + 1800}{2} = 1500$。再算变化量：$\Delta P = 24 - 30 = -6$，$\Delta Q = 1800 - 1200 = 600$。代入弧弹性公式：

$$E_d = \frac{\Delta Q / \bar{Q}}{\Delta P / \bar{P}} = \frac{600 / 1500}{-6 / 27} = \frac{0.4}{-0.2222} = -1.8$$

取绝对值 $|E_d| = 1.8 > 1$，该区间内需求富有弹性。比较降价前后总收益：

- 降价前：$R_1 = 30 \times 1200 = 36{,}000$ 元
- 降价后：$R_2 = 24 \times 1800 = 43{,}200$ 元

总收益增加 7{,}200 元。结论：$|E_d| > 1$ 时降价提高总收益；$|E_d| < 1$ 时降价降低总收益；$|E_d| = 1$ 时总收益不变。

## 例题 2：线性需求下的点弹性与消费者剩余

某市场的线性需求曲线为 $P = 100 - 2Q$，市场均衡价格为 40 元。分别求均衡数量处的点弹性与消费者剩余。

**解答**

均衡数量：$40 = 100 - 2Q^*$，得 $Q^* = 30$。需求曲线斜率 $\frac{dQ}{dP} = -\frac{1}{2}$（或写成 $Q = 50 - \tfrac{P}{2}$，故 $\frac{dQ}{dP} = -\tfrac12$）。点弹性：

$$E_d = \left|\frac{dQ}{dP} \cdot \frac{P}{Q}\right| = \frac{1}{2} \times \frac{40}{30} = \frac{2}{3} < 1$$

需求缺乏弹性。消费者剩余是需求曲线下方、价格线 $P = 40$ 以上的三角形面积。需求曲线在 $Q = 0$ 处的截距为 100，在 $P = 0$ 处与数量轴交于 $Q = 50$：

$$CS = \frac{1}{2} \times (100 - 40) \times 30 = 900 \text{ 元}$$

注意区分：如果用整个需求曲线的三角形（高 100、底 50）来算，得到的是「价格为 0 时」的剩余；计算某价格下的消费者剩余，三角形的顶边必须是该价格线。

## 例题 3：用替代效应与收入效应分解价格下降

某消费者只购买商品 X 和商品 Y。X 的价格从 10 元降至 8 元，名义预算保持 100 元不变。替代效应使 X 的购买量从 5 件增至 6 件；随后预算「实际效应」使购买量再增 1 件至 7 件。

**解答**

- **替代效应**：$+1$ 件（$5 \to 6$）。消费者在保持原消费束购买力不变的补偿预算下，把消费转向更便宜的 X；
- **收入效应**：$+1$ 件（$6 \to 7$）。价格下降使实际收入上升，对正常品 X 而言多买；
- **总效应**：$+2$ 件（$5 \to 7$）。

判定准则：收入效应为正说明 X 是正常品；若收入效应为负（购买量减少），X 是劣等品；若劣等品的收入效应绝对值超过替代效应，则 X 是吉芬商品。

## 例题 4：弹性与税收归宿

某市场汽油需求曲线为 $Q_d = 2400 - 300P$（$Q$ 单位：百升/月，$P$ 单位：元/升），供给曲线为 $Q_s = 600 + 300P$。现对该品征收 1 元/升的从量税。求课税前后的均衡，并分析税负在买卖双方的分担。

**解答**

**课税前**：联立 $2400 - 300P = 600 + 300P$，得 $P^* = 3$ 元，$Q^* = 2400 - 900 = 1500$ 百升。此点需求点弹性 $E_d = 300 \times 3 / 1500 = 0.6$，供给点弹性 $E_s = 300 \times 3 / 1500 = 0.6$，双方弹性相等。

**课税后**：从量税使买价与卖价相差 1 元，$P_b = P_s + 1$。联立 $Q_d(P_b) = Q_s(P_s)$：

$$2400 - 300(P_s + 1) = 600 + 300P_s \;\Longrightarrow\; 2100 = 600 + 600P_s \;\Longrightarrow\; P_s = 2.5,\ P_b = 3.5$$

交易量 $Q' = 2400 - 300 \times 3.5 = 1350$ 百升。

**税负分担**：消费者买价从 3 元升至 3.5 元，负担 $0.5$ 元/升；生产者卖价从 3 元降至 2.5 元，负担 $0.5$ 元/升。各占 50%，与双方弹性相等一致。一般结论：**税负分担比例与各自弹性的倒数成正比——哪一方弹性越小，哪一方承担越多税负**；同时交易量由 1500 降至 1350 百升，产生无谓损失。

**无谓损失的量化**。税负使交易量由 1500 降至 1350 百升。无谓损失（deadweight loss, DWL）是未发生交易的边际价值与边际成本之差在 $[1350, 1500]$ 区间上的积分：

$$DWL = \int_{1350}^{1500} \left[ P_d(Q) - P_s(Q) \right] dQ$$

需求反函数 $P_d(Q) = 8 - Q/300$，供给反函数 $P_s(Q) = -2 + Q/300$，价差为 $(8 - Q/300) - (-2 + Q/300) = 10 - 2Q/300$。在端点 $Q = 1500$ 处价差为 0；在 $Q = 1350$ 处价差为 $10 - 9 = 1$（恰等于税额 1 元）。价差随 $Q$ 线性下降，故 $DWL = \tfrac{1}{2} \times 1 \times (1500 - 1350) = 75$ 百升·元 = 7500 元。这就是「税的超额负担」：买卖双方合计因交易减少而净损失的部分。

## 例题 5：弹性与总收益的数值例（需求曲线上的三段判断）

某厂商面临需求曲线 $Q = 300 - 3P$，边际成本恒为 20 元。求：(a) 利润最大化的价格与产量；(b) 判断 $P = 40$、$P = 50$、$P = 80$ 三处分别处于哪一弹性区间，并据此判断涨价或降价能否提高总收益；(c) 用总收益数值验证「涨价增收仅发生在缺乏弹性段」的结论。

**解答**

**(a) 利润最大化**。需求反函数 $P = 100 - Q/3$，边际收益 $MR = 100 - 2Q/3$。利润最大化条件 $MR = MC = 20$：

$$100 - \frac{2Q}{3} = 20 \;\Longrightarrow\; Q^* = 120,\; P^* = 100 - 40 = 60 \text{ 元}$$

验证弹性：$|E_d| = \left|\dfrac{dQ}{dP}\right| \cdot \dfrac{P}{Q} = 3 \times \dfrac{60}{120} = 1.5 > 1$，满足垄断定价条件（定价落在富有弹性段）。

**(b) 三处弹性判断**。该需求曲线 $|E_d| = \dfrac{3P}{300 - 3P}$，中点 $P = 50$ 处 $|E_d| = 1$（单位弹性）：

| 价格 | $|E_d|$ | 弹性区间 | 涨价能否增收 | 降价能否增收 |
|---|---|---|---|---|
| $P = 40$ | $0.67$ | 缺乏弹性 | 能 | 不能 |
| $P = 50$ | $1.00$ | 单位弹性 | 不能 | 不能（$dR/dP = 0$） |
| $P = 80$ | $4.00$ | 富有弹性 | 不能 | 能 |

**(c) 数值验证**。取缺乏弹性段 $P_1 = 40$ 涨价至 $P_2 = 45$：

$$R_1 = 40 \times (300 - 120) = 40 \times 180 = 7200 \text{ 元},\qquad R_2 = 45 \times (300 - 135) = 45 \times 165 = 7425 \text{ 元}$$

涨价增收 225 元，验证「缺乏弹性段涨价增收」。

取富有弹性段 $P_3 = 80$ 降价至 $P_4 = 70$：

$$R_3 = 80 \times (300 - 240) = 80 \times 60 = 4800 \text{ 元},\qquad R_4 = 70 \times (300 - 210) = 70 \times 90 = 6300 \text{ 元}$$

降价增收 1500 元，验证「富有弹性段降价增收」。

**关键结论**：$|E_d| = 1$ 的单位弹性点是总收益的极值点（$dR/dP = 0$）；在该点左侧（$|E_d| < 1$）涨价增收，右侧（$|E_d| > 1$）降价增收。经营判断必须落在弹性分段框架内，而不是「价格涨跌决定收益涨跌」的朴素直觉。

# 五、易错点辨析

1. **把斜率当弹性**。需求曲线越「陡」不代表弹性越大。弹性是相对变化之比，同一条直线上高价处弹性大、低价处弹性小。
2. **弧弹性用错基数**。涨价与跌价算出的弹性不对称，是基期选择问题，不是需求曲线不对称。中点法（弧弹性）消除该问题。
3. **混淆交叉弹性的两个方向**。$E_{xy}$ 是「x 的量对 y 的价格」的反应，与 $E_{yx}$ 一般不相等。
4. **把劣等品等同于吉芬商品**。劣等品（$E_I < 0$）范围远大于吉芬商品：吉芬商品必须收入效应绝对值大于替代效应。大多数劣等品（如低档服装）降价仍会多买。
5. **计算消费者剩余时顶边取错**。必须是「价格线」而非需求曲线与数量轴交点构成的整个三角形。
6. **总收益判断只看价格涨跌**。必须结合弹性：$|E_d| > 1$ 降价增收，$|E_d| < 1$ 涨价增收。
7. **税负分担的方向记反**。哪一方弹性小，哪一方负担多：对需求缺乏弹性的奢侈品征税，税负主要落在消费者；对供给缺乏弹性的农产品征税（如出口关税），税负主要落在生产者。
8. **把「长期弹性更大」当成万能公式**。长期弹性更大的原因是有时间调整消费与供给结构，但若商品本身没有替代品（如胰岛素），无论短期长期都缺乏弹性。

# 七、专题：弹性与垄断定价

本章最后把弹性概念放到市场结构里：为什么垄断厂商要「看弹性定价」，而完全竞争厂商只能「接受价格」。

**竞争 vs 垄断的需求面对**。完全竞争厂商面对的是水平需求曲线（$E_d \to \infty$），边际收益等于价格，厂商只能按市价出售。垄断厂商面对的是整条向下倾斜的市场需求曲线（$E_d$ 有限），必须自己选择价格，边际收益低于价格：

$$MR = P\left(1 - \frac{1}{|E_d|}\right)$$

利润最大化条件 $MR = MC$ 直接给出**弹性加成定价规则**：

$$P = \frac{|E_d|}{|E_d| - 1}\, MC$$

**两个推论**：

1. $|E_d|$ 越大（需求越平），加成 $|E_d|/(|E_d|-1)$ 越接近 1，价格越贴近边际成本；
2. 若 $|E_d| < 1$（需求曲线该段过于陡峭），$MR < 0$，厂商绝不会在此段定价——垄断定价必然落在 $|E_d| > 1$ 的富有弹性区间。

**例题 5：弹性加成定价**。某垄断厂商边际成本恒为 60 元，市场需求 $Q = 500 - 5P$。求利润最大化价格与产量，并验证该点弹性大于 1。

**解答**：由 $Q = 500 - 5P$ 得 $P = 100 - Q/5$，故 $|E_d| = \frac{P}{100 - P} \times \frac{5}{...}$。更直接地用 $\frac{dQ}{dP} = -5$，$|E_d| = 5 \cdot P/Q$。需求曲线截距 100，故在 $Q^* = 500 - 5P$ 处 $|E_d| = 5P/(500 - 5P)$。

利润 $\pi = (P - 60)Q = (P-60)(500 - 5P)$。对 $P$ 求导：

$$\frac{d\pi}{dP} = (500 - 5P) - 5(P - 60) = 800 - 10P = 0 \;\Longrightarrow\; P^* = 80,\; Q^* = 100$$

验证：$|E_d| = 5 \times 80/100 = 4 > 1$，满足垄断定价的弹性条件。用加成公式交叉验证：$P = \frac{|E_d|}{|E_d|-1} MC$，在 $P = 80$ 处 $|E_d| = 4$，得 $P = 4/3 \times 60 = 80$，一致。

# 八、弹性在实证研究中的应用（实证视角）

## 8.1 需求弹性的估计方法

本章的弹性定义是「局部百分比之比」，但实证研究面对的是观测数据，需要用统计方法估计弹性。最基础的方法是对数—对数回归（log-log regression）：

$$\ln Q_i = \alpha + \beta \ln P_i + \varepsilon_i$$

对数求导后 $\beta$ 恰好就是需求价格弹性的估计值（$\frac{d \ln Q}{d \ln P}$），即价格上升 1% 时需求量平均下降 $\beta\%$。这条方法之所以常用，是因为：

1. **弹性恒定性假设**：对数—对数模型隐含「任意价格水平弹性相同」（恒弹性，constant elasticity），而原水平回归 $\Delta Q = \beta \Delta P$ 的斜率随价格变化；
2. **百分比直接对应**：系数 $\beta$ 直接就是弹性，解读无需换算；
3. **异方差缓解**：对数变换缩小了价格与数量级的差异，回归残差更稳定。

**局限**：对数—对数模型要求 $P, Q > 0$，对零观测无能为力；弹性恒定性假设在长尾价格区间可能失真（高端弹性小、低端弹性大），实务中常用分段回归或加入价格平方项做修正。

## 8.2 弹性估计的识别困难

观测数据中的价格与需求量同时受「需求方因素」（收入、偏好、替代品价格）与「供给方因素」（成本、技术、政策）影响，直接对 $P$ 与 $Q$ 做回归会得到「供给曲线污染」的弹性——**相关不等于因果**。经典识别策略有三类：

- **工具变量法**（IV）：找一个只影响价格但不直接影响需求的变量（如原材料国际价格、运输成本、自然灾害）作为 $P$ 的工具变量；
- **政策实验**（断点、自然实验）：利用税收、管制、补贴等外生政策冲击造成的价格跳跃，把冲击前后的需求变化归因于价格本身；
- **结构估计**：假设需求函数具体形式（如常弹性、线性），联合识别需求与供给两个方程。

理解「弹性估计需要识别」是读实证文献的基本门槛——很多「需求弹性」估计实际上是「价格-数量回归」而非因果弹性。

## 8.3 弹性的国际比较与实证基准

国际实证研究（如美国食品、能源、医疗服务的需求弹性估计）给出了一些经验基准，便于做新研究时的对照：

| 商品 | 经验弹性区间 | 时间 | 主要驱动 |
|---|---|---|---|
| 汽油 | $-0.3 \sim -0.6$ | 短期 | 无替代品 + 出行刚需 |
| 汽油（长期） | $-1.0 \sim -1.5$ | 长期 | 换车 + 迁居 |
| 烟草 | $-0.4 \sim -0.6$ | 长期 | 成瘾性 |
| 电力 | $-0.2 \sim -0.4$ | 短期 | 无替代 + 合同约束 |
| 奢侈品服装 | $-1.5 \sim -3.0$ | 短期 | 替代品多 + 可推迟 |
| 大米 | $-0.1 \sim -0.3$ | 长期 | 基础食品 + 必需 |

这些数字是**区间**而非精确值，因市场、时段、测量口径不同而异；但它们说明：

1. 必需品弹性普遍小于 1，奢侈品大于 1；
2. 长期弹性显著大于短期弹性（汽油、电力最典型）；
3. 成瘾品（烟草、酒精）弹性低且长期变化不大。

读一篇实证论文时，先看其弹性估计是否落在此类经验区间内，再判断其识别策略是否可信，是快速评估研究质量的一个实用方法。

## 8.4 本章知识图谱

把本章知识点画成一张图，便于最后整体回顾：

```
弹性（无单位的敏感度）
├── 需求侧
│   ├── 需求价格弹性 E_d（点 / 弧 / 中点）
│   ├── 收入弹性 E_I（正常 / 奢侈品 / 必需 / 劣等）
│   └── 交叉弹性 E_xy（替代 / 互补 / 独立）
├── 供给侧
│   ├── 供给价格弹性 E_s（短期 < 长期）
│   └── 替代弹性（要素 / 商品间替代强度）
├── 应用
│   ├── 总收益与定价（弹性区间 × 价格方向）
│   ├── 税收归宿（弹性小的一方负担多）
│   └── 垄断定价（E_d > 1 区间 + 加成公式）
└── 消费者福利
    ├── 消费者剩余 CS（价格线上方面积）
    ├── 生产者剩余 PS（供给线上方面积）
    └── 无谓损失 DWL（偏离均衡的消失面积）
```

价格变动 → 替代效应 + 收入效应 → 吉芬商品（极端情形）。

## 附录 B：公式速查表

| 公式 | 表达式 | 适用场景 |
|---|---|---|
| 点弹性 | $E_d = \left\lvert \dfrac{dQ}{dP} \cdot \dfrac{P}{Q} \right\rvert$ | 需求曲线上某点 |
| 弧弹性（中点法） | $E_d = \dfrac{\Delta Q / \bar{Q}}{\Delta P / \bar{P}}$ | 两点区间，消除基期歧义 |
| 收入弹性 | $E_I = \dfrac{\Delta Q / Q}{\Delta I / I}$ | 商品档次判断 |
| 交叉弹性 | $E_{xy} = \dfrac{\Delta Q_x / Q_x}{\Delta P_y / P_y}$ | 商品关系判断 |
| 供给弹性 | $E_s = \dfrac{\Delta Q_s / Q_s}{\Delta P / P}$ | 短期 vs 长期 |
| 总收益一阶条件 | $\dfrac{dR}{dP} = Q(1 - E_d)$ | 涨价/降价增收判断 |
| 消费者剩余（线性） | $CS = \tfrac{1}{2}(a - P^*) Q^*$ | 需求 $P = a - bQ$ |
| 生产者剩余（线性） | $PS = \tfrac{1}{2}(P^* - c) Q^*$ | 供给 $P = c + dQ$ |
| 税负分担 | $\dfrac{\text{消费者负担}}{\text{生产者负担}} = \dfrac{E_s}{E_d}$ | 从量税归宿 |
| 无谓损失（从量税） | $DWL = \tfrac{1}{2} \cdot t \cdot (Q^* - Q')$ | 税额 $t$ 的交易量损失 |
| 垄断加成定价 | $P = \dfrac{E_d}{E_d - 1} MC$ | 利润最大化 |

# 十一、小结

本章建立了需求弹性与消费者福利分析的基本框架。要点回顾：

1. 需求价格弹性区分了富有弹性（$|E_d| > 1$）、缺乏弹性（$|E_d| < 1$）与单位弹性（$|E_d| = 1$）三种情形，直接决定「降价是否提高总收益」这一经营决策问题。弹性是区间量而非点量，弧弹性用中点基数消除基期歧义。
2. 收入弹性与交叉弹性是判断商品档次和市场结构关系（替代/互补）的基础指标；恩格尔定律是收入弹性的典型经验规律。弹性还随时间尺度（短期 vs 长期）与市场范围（窄市场 vs 宽市场）变化。
3. 消费者剩余与生产者剩余构成福利分析的核心；总剩余在完全竞争均衡下达到最大，偏离均衡产生无谓损失。价格管制（最高限价、最低限价）的福利代价在图形上都体现为消失的三角形面积。
4. 价格变动的总量效应可分解为替代效应（保持实际购买力不变，恒为负）与收入效应（对正常品为正），两者方向可能一致也可能相反；吉芬商品是两者反向且收入效应压倒时的极端情形，必须同时满足「劣等品」与「收入效应绝对值大于替代效应」两个条件。
5. 弹性直接服务于三大场景：总收益与定价（富有弹性降价增收、缺乏弹性涨价增收）、税收归宿（弹性小的一方负担多税负）、垄断定价（利润最大化要求落在 $E_d > 1$ 区间，$P = \frac{E_d}{E_d - 1} MC$）。
6. 实证研究通过「对数—对数回归 + 识别策略」估计弹性；经验基准（汽油 $-0.3 \sim -1.5$、烟草 $-0.4 \sim -0.6$）是快速评估新研究可信度的对照工具。

下一章将进入生产理论与成本分析，届时会看到弹性概念如何扩展到供给侧——生产要素的替代弹性将决定长期生产的要素比例。
