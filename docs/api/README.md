# LearnRise API 文档

本目录同时存放**自动生成**与**手工维护**两类文档。两者混排在同一目录，请务必先看清下方清单，不要改错文件。

## 快速入口

- `openapi.json`（仓库根目录）：运行时导出的完整 OpenAPI 3.1 文档，是机器可读的唯一真源。
- `docs/api/<tag>.md`：按 OpenAPI tag 切分的 Markdown 端点文档。
- `docs/api/conventions.md`：**手写**的统一 API 约定（仅约束新端点）。
- 服务启动后可直接访问 Swagger UI：<http://localhost:8000/api/docs>。

## 重新生成

生成脚本必须在后端镜像内运行：后端固定 Python 3.11，宿主机的 Python 3.14 无法导入项目依赖。

```bash
# 在 LearnRise 仓库根目录执行（会挂载整个仓库到容器的 /repo）
docker compose run --rm -v "$PWD:/repo" -w /repo backend \
  python scripts/gen_api_docs.py
```

脚本会：

1. 在进程内 `import app.main` 并调用 `app.openapi()`（不需要先启动 HTTP 服务）；
2. 以 `sort_keys=True`、固定的分组与端点顺序写入 `openapi.json`；
3. 为每个 tag 生成一个 `docs/api/<tag>.md`，包括尚未有端点的占位分组。

成功时打印形如：

```text
wrote openapi.json (N paths, M operations) and docs/api (K files)
```

## 本地预览

```bash

python3 -c "import json; d=json.load(open('openapi.json')); print(len(d['paths']))"

# 启动后端后浏览 Swagger UI / ReDoc
docker compose up -d db backend
# Swagger UI:  http://localhost:8000/api/docs
# ReDoc:       http://localhost:8000/api/redoc

# Markdown 文件用任意 Markdown 渲染器查看，例如
#   npx @redocly/cli preview-docs openapi.json
```

## 生成物勿手改

以下文件由 `scripts/gen_api_docs.py` 全量生成，**禁止手工编辑**（每个文件首行都有 `GENERATED BY` 横幅）：

- `openapi.json`
- `docs/api/auth.md`
- `docs/api/competitions.md`
- `docs/api/sources.md`
- `docs/api/quiz.md`
- `docs/api/review.md`
- `docs/api/assistant.md`
- `docs/api/dashboard.md`
- `docs/api/agents.md`
- `docs/api/knowledge-points.md`
- `docs/api/explain.md`
- `docs/api/internal.md`
- `docs/api/health.md`
- `docs/api/notes.md`

需要修改上述内容时，请修改 `backend/app/api/**` 中的路由/响应模型，然后重新运行生成脚本；直接手改会在下一次生成时被覆盖。

以下文件为**手工维护**，不会被脚本覆盖：

- `docs/api/README.md`（本文件）
- `docs/api/conventions.md`

## CI 漂移检查

生成物必须与代码保持零差异。CI（或本地提交前）执行：

```bash
docker compose run --rm -v "$PWD:/repo" -w /repo backend \
  python scripts/gen_api_docs.py
git diff --exit-code -- openapi.json docs/api
```

`git diff --exit-code` 返回 0 表示生成物与仓库中的版本一致；非 0 表示有人手改了生成物，或改了路由却忘记重新生成。
